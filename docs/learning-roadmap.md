# Python Learning Roadmap

## Learning philosophy

Learn Python by building small projects rather than memorizing syntax from a book. Keep the experience practical and enjoyable with game-like exercises, puzzles, and coding challenges.

The recommended approach is **Practical + Project-Based + Daily Challenge**.

## 1. Expected learning timeline

Assuming approximately 30–45 minutes of study per day:

| Period | Level / focus | Topics and activities |
|---|---|---|
| Weeks 1–2 | Beginner | Python fundamentals, variables, data types, operators, and conditions |
| Weeks 3–4 | Problem solving | Loops, lists, dictionaries, functions, and error handling |
| Weeks 5–6 | Intermediate | Files, JSON, CSV, modules, OOP, and SQLite |
| Weeks 7–8 | Projects | Expense Tracker, Tax Calculator, and Inventory System |
| Weeks 9–12 | Practical Python | APIs, automation, databases, and real-world projects |

### Estimated milestones

| Goal | Estimated time |
|---|---:|
| Understand Python fundamentals | 2–4 weeks |
| Write programs independently | 1–2 months |
| Build small projects | 2–3 months |
| Apply Python to practical tasks | 3–6 months |

These are estimates and depend on regular practice and prior experience.

## 2. Daily learning format

Each lesson follows five parts:

1. **Learn (5–10 minutes):** Understand one concept in clear, simple language.
2. **Code (10 minutes):** Write and run code hands-on.
3. **Challenge (10 minutes):** Solve a puzzle, quiz, or coding challenge.
4. **Mini Project (10 minutes):** Combine the concepts in a small program.
5. **Review & XP:** Review the solution, correct mistakes, and track progress or level-ups.

The learner should write and think through the code. The instructor reviews submitted solutions and explains mistakes instead of only providing finished code.

## 3. Project path

| Project | Target period | Purpose |
|---|---|---|
| Simple Calculator | Week 1 | Practice basic input, output, and calculations |
| Expense Tracker | Weeks 2–3 | Practice data handling and basic program structure |
| Inventory System | Weeks 4–6 | Apply programming concepts to stock management |
| Hotel Management | Weeks 7–10 | Apply Python to a larger practical workflow |

Later learning can extend to SQLite databases, REST APIs, automation, and AI integration.

## 6. Learning style options

The learning style can be selected or adjusted as the course progresses:

- **Project-Based:** Learn by building projects.
- **Game-Based:** Learn through puzzles, quizzes, and challenges.
- **Mixed:** Combine lessons, games, challenges, and projects.

**Recommended:** Mixed Learning, to keep lessons engaging while building practical skills.

## 7. Daily study time options

- 15–20 minutes
- 30–45 minutes
- 1 hour

The roadmap's timeline assumes 30–45 minutes per day. Adjust the pace if the available study time changes.
