# Day 01 — Introduction and First Program

## Goals
- Understand what Python is used for.
- Check that Python is installed.
- Run a first Python program.
- Use `print()` to display output.

## Check Python
```bash
python3 --version
```

## First program
Create `hello.py`:
```python
print("Hello, Python!")
print("I am learning Python step by step.")
```
Run it: `python3 hello.py`

## Challenge
Write a program that prints your name, your city, and one reason you want to learn Python.

## Reflection
- What did `print()` do?
- What happened when you changed the text?
