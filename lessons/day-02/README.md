# Day 02 — Variables and Data Types

## Goals
- Store values in variables.
- Recognize strings, integers, floats, and booleans.
- Display variable values.

## Example
```python
name = "Alex"
age = 25
height = 1.75
is_learning = True

print(name)
print(age)
print(height)
print(is_learning)
```

## Challenge
Create variables for a product name, quantity, and unit price. Print them in a readable sentence.

## Reflection
- Which values are strings?
- What is the difference between an integer and a float?
